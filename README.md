# Tele-Safe Guard

A safety platform that helps people and organisations stay protected from scams,
hacking and the theft of personal information. It teaches, helps victims, detects
scams and tracks reports.

## Structure
- backend/  API and detection logic (Python, FastAPI)
- frontend/ Website (Next.js, TypeScript)
- content/  Lessons and knowledge base (English, Kinyarwanda)
- docs/     Project documentation
- infra/    Docker and deployment
